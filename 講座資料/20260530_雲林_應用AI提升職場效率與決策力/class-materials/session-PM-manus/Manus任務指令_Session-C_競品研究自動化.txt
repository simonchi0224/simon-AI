Session C：Manus 競品研究自動化
工具：Manus（https://manus.im）

═══ 先讓大家看到 Manus 跟 ChatGPT 的差異 ═══

ChatGPT：你問 → 它答 → 你自己去查、整理、存檔
Manus：你下任務 → 它自己搜尋、整理、生成報告 → 交給你一份完成品

示範任務（老師先跑給大家看，約 5–10 分鐘）：
──────────────────────────────────────────
「請幫我研究台灣手工包與手工編織包的品牌市場。
 任務：
 1. 找出 5 個台灣在地手工包品牌
 2. 整理每個品牌的：名稱、主要產品、定價區間、銷售通路、IG 粉絲數（估計即可）
 3. 分析這個市場的 3 個趨勢
 4. 根據以上資料，給出一個剛起步的雲林手工藤編品牌「芒草工坊」
    最值得切入的差異化方向
 請用表格 + 文字摘要的方式呈現，最後存成一份報告。」
──────────────────────────────────────────

觀察重點讓學員看：
  - Manus 自己開瀏覽器搜尋
  - 它自己整理資料
  - 它自己生成報告
  - 你沒有動手做任何一個步驟

═══ 學員自己跑的任務 ═══

請每位學員根據自己的創業方向，改寫以下任務模板：

模板：
「請幫我研究 [你的行業/產品類別] 的市場。
 任務：
 1. 找出 5 個競品或類似業者
 2. 整理每個的：名稱、主要服務/產品、定價、目標客群、特色
 3. 分析市場的 2–3 個趨勢或機會
 4. 根據以上，給我 [你的品牌/事業] 一個具體的切入建議
 請用表格 + 文字摘要呈現，儲存成報告。」

各背景學員的方向建議：
  代購業主 → 「日本或韓國美妝代購市場」
  房地產  → 「雲林新興重劃區租屋市場」
  學生    → 「大學生創業服務平台競品」
  上班族  → 「台灣手作市集品牌趨勢」
  （警察可選任一感興趣的副業方向）

═══ Manus 使用注意事項 ═══
1. 任務要說清楚，模糊的任務跑出模糊的結果
2. 它可能跑 5–15 分鐘，這很正常，不是卡住
3. 結果要人工核對，它可能搜尋到舊資料或估算錯誤
4. 可以追加指令：「請把這份報告加上一個執行優先順序建議」
