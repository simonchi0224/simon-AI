# 產品與 QC 作業指引（課堂虛構資料）

**資料聲明：** 以下型號、規格和流程全為虛構示例，並非匯聯實業正式產品資料或核准 SOP。實務操作須依公司文件及授權人員指示。

## GP-4801｜進氣壓力檢查示例

- 練習表列範圍：4.5–5.5 bar（Mock Spec Rev A，第 2 節）
- 檢驗紀錄：5.1 bar
- 回答時需附來源與單位；只說明數值是否位於「本練習表列範圍」，不得延伸成正式放行結論。

## GP-4801｜扳機力檢查示例

- 練習表列範圍：18–25 N（Mock Spec Rev A，第 3 節）
- 檢驗紀錄：26.4 N，備註「偏緊，待複測」
- 整理差異及待辦，不得自行修改規格或省略複測。

## GP-4810｜空氣消耗量示例

- 練習表列範圍：180–220 L/min（Mock Spec Rev B，第 1 節）
- 檢驗紀錄：205 L/min
- 回答需保留 L/min，並標明規格版本。

## GP-4810｜本體長度示例

- 練習表列範圍：128–132 mm（Mock Spec Rev B，第 2 節）
- 檢驗紀錄未填數值
- 應回答「未提供」，不可自行推估。

## 虛構作業步驟

1. 確認量具狀態；標示逾期或不清楚時停用並回報。
2. 記錄原始數值、單位、型號、批次與檢驗項目。
3. 發現差異時隔離樣品並通知主管，依核准規範複測。
4. 記錄處理人、時間及後續狀態；不得自行更動規格上下限。

## 回答規則

- 只依本來源回答，每一項附上對應小節或表名。
- 找不到資料時明確寫「來源未提供」。
- 不把練習資料轉成正式合格／不合格或放行判定。
